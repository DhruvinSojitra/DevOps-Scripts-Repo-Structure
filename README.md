# 🚀 DevOps Automation Scripts

This repository contains a structured collection of automation scripts to install, configure, and manage popular DevOps tools on Ubuntu-based systems.

## 📌 Purpose
The goal of this repository is to simplify and automate the setup of DevOps tools using reusable shell scripts and infrastructure practices. It is designed for learning, real-world usage, and quick environment setup.

## 🛠️ Tools Covered

- Jenkins (CI/CD)
- Docker (Containerization)
- Kubernetes (Orchestration)
- Nginx (Web Server)
- Prometheus & Grafana (Monitoring)

## 📂 Project Structure

- `scripts/` → Installation and setup scripts
- `configs/` → Configuration files
- `docs/` → Documentation and setup guides
- `ansible/` → Automation using Ansible
- `terraform/` → Infrastructure as Code (optional)
