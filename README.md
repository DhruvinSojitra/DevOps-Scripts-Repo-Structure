## 🎯 Purpose

The goal of this repository is to simplify and automate the setup of DevOps tools using reusable shell scripts.  
It helps in:

- Quick environment setup ⚡  
- Reducing manual effort 🤖  
- Learning DevOps in a practical way 📚  

---

## 🛠️ Tools Covered

- Jenkins (CI/CD)
- Docker (Containerization)
- Kubernetes (Orchestration)
- Nginx (Web Server)
- Prometheus & Grafana (Monitoring)

---

## 📂 Project Structure

- `scripts/` → Installation and setup scripts  
- `configs/` → Configuration files  
- `docs/` → Documentation and setup guides  
- `ansible/` → Automation using Ansible  
- `terraform/` → Infrastructure as Code
